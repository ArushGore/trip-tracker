# Trip Tracker Backend (`app`)

Go + HTMX + PostgreSQL backend monolith for Trip Tracker.

- Runs inside a Docker container on **OrbStack** in local development (with port forwarding to the host browser and mobile simulator on a non-SSL port).
- Serves both HTMX web views and JSON API endpoints for the Flutter mobile app (`/mobile`).
- See [`../wiki/wiki/architecture.md`](../wiki/wiki/architecture.md) for architecture details and [`../wiki/wiki/sdlc-process.md`](../wiki/wiki/sdlc-process.md) for the mandatory 5-step SDLC workflow.
