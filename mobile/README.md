# Trip Tracker Mobile (`mobile`)

Flutter mobile client for Trip Tracker.

- **Phase 1**: Connects to the Trip Tracker `/app` backend (over port `443` in production and non-SSL port in local dev) with full UI parity.
- **Phase 2**: Supports optional standalone Google Sheets backend via Google Drive integration.
- See [`../wiki/wiki/architecture.md`](../wiki/wiki/architecture.md) for architecture details and [`../wiki/wiki/sdlc-process.md`](../wiki/wiki/sdlc-process.md) for the mandatory 5-step SDLC workflow.
